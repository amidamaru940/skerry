# Network address allowlist for Skerry (fork of Atoll).
#
# tests/test_network_allowlist.py collects every "http://" / "https://" string
# literal from the app sources (DynamicIsland/) and fails when one is missing
# here, or when an entry here no longer appears in the sources.
# A URL is cut where string interpolation starts, e.g. "https://lrclib.net/api/search?track_name=".
#
# Format:  URL | feature | how it is enabled (Defaults key = value, or a note)
# Everything that makes requests is off by default (Skerry phase 3).
