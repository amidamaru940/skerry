# Code of Conduct

Skerry follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, personal attacks and sharing other people's private information are not tolerated anywhere in the project.

To report a problem, open an issue marked "conduct", or contact the maintainer through their GitHub profile if the matter is private. Reports are handled confidentially.
