## Зачем Skerry

**Скриншоты пачками.** Делай скриншоты как обычно (⇧⌘3, ⇧⌘4, ⇧⌘5). Они складываются в пачку у выреза, и кнопка **«Вставить в Claude · 3»** вставляет всю пачку в приложение, где ты работал. Можно выбрать нужные снимки, перетащить пачку куда угодно, разметить снимок или отправить его по AirDrop. По желанию в пачку попадают и снимки в буфер (⌃⇧⌘3/4). Они хранятся во временной папке и удаляются в течение суток.

**История буфера, которой можно доверять.**
- Всё скопированное — карточками, с поиском (понимает русский), фильтрами и закреплением.
- Пароли не записываются: ни из менеджеров паролей (они помечают копию как секретную), ни из приложений, которые ты исключил.
- История живёт только в памяти, если не включить сохранение на диск.
- Записи удаляются через сутки, одноразовые коды — через 2 минуты.

**Музыка — спокойно.** Обложка, название и ⏮ ⏯ ⏭ видны всегда. Перемешивание, повтор, громкость, вывод звука и тексты появляются, когда курсор над плеером. Рядом **«Далее»** — ближайшие события календаря. Источник **«Авто»** сам выбирает между Spotify, «Музыкой» и браузером, а видео без названия трека, например Reels в соседней вкладке, плеер не перехватывает. Свайп по свёрнутому вырезу переключает треки.

**Мелочи, сделанные как надо.**
- **«Не засыпать»** с таймером.
- **Полка** для файлов, брошенных на вырез.
- **Пипетка**: копирует цвет и показывает его у выреза, не забирая фокус.
- **Компактный вид**: плеер в одну строку.
- **Горячие клавиши**.
- **Русский и английский**.
- Пока экран показывается или записывается, буфер и скриншоты показывают только заголовки, а вырез молчит.

## Приватность

По умолчанию Skerry **ничего не отправляет в сеть и не слушает портов**.

Каждый сетевой адрес из исходников записан в [`tests/network_allowlist.txt`](tests/network_allowlist.txt) с указанием функции и настройки, которая её включает. Новый адрес без записи ломает тест.

| Функция (включается отдельно) | Что уходит с Mac и куда |
|---|---|
| Погода на экране блокировки | приблизительное место → wttr.in или open-meteo.com |
| Тексты песен | название и исполнитель → lrclib.net, music.163.com (спрашивает перед включением) |
| Значок «explicit», имена исполнителей | название трека → itunes.apple.com, open.spotify.com |
| Анимированные обложки Apple Music | запрос к api.music.apple.com |
| «Лайк» и Canvas в Spotify | вход в Spotify, api.spotify.com |
| Помощник (Screen Assistant) | **скриншоты и текст** → выбранный ИИ-сервис или локальный Ollama |
| Расход ИИ (Claude, Codex, Cursor…) | токены из связки ключей → эти сервисы |
| Сторонние расширения, LocalSend, Quick Share | локальный порт этого Mac / локальная сеть |

История буфера хранится только в памяти, пока не включено сохранение. Скриншоты, снятые в буфер, лежат файлами во временной папке и удаляются в течение суток. Аналитики нет. Проверка обновлений (Sparkle) выключена, автообновлений нет. У «зеркала» нет разрешения на камеру.

## Требования

- Mac с чипом Apple (M1 или новее). Сборка только для arm64.
- macOS 14.6 или новее.
- Сделан для MacBook с вырезом. На экранах без выреза Skerry показывает плавающий остров (проверено только на MacBook Pro с вырезом).

## Установка

1. Скачай `Skerry-<версия>.dmg` из [Releases](../../releases), перетащи **Skerry** в «Программы» и открой.
2. macOS скажет, что не может проверить разработчика. Открой **Системные настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»** рядом со Skerry.
3. Проверка скачанного файла (по желанию): `shasum -a 256 -c Skerry-<версия>.dmg.sha256` (запускай рядом с файлом `.sha256`).

## Разрешения

Каждое запрашивается только тогда, когда оно нужно функции.

| Разрешение | Зачем |
|---|---|
| Универсальный доступ | нажать ⌘V, чтобы вставить скриншоты в приложение на переднем плане; перехватывать клавиши громкости и яркости для собственного HUD |
| Календарь | показывать ближайшие события |
| Автоматизация (Музыка, Spotify) | управление плеером |
| Доступ к папке скриншотов | собирать скриншоты, сохранённые в папку (снимкам в буфер доступ не нужен) |

## Безопасность

- Skerry бесплатный и подписан ad-hoc. Он **не нотаризован** Apple (платного аккаунта разработчика нет), поэтому macOS предупреждает при первом запуске.
- Для macOS каждое обновление — новое приложение. После обновления разреши Универсальный доступ заново.
- Из-за ad-hoc подписи приложению приходится разрешать загрузку собственных встроенных фреймворков (`disable-library-validation`). Сборке с нотаризацией по Developer ID это не понадобилось бы.
- Скачивай Skerry только из Releases этого репозитория.
- О уязвимостях сообщай приватно: см. [SECURITY.md](SECURITY.md).

## Обновление

Скачай новый DMG, замени Skerry в «Программах» и снова разреши Универсальный доступ.

## Удаление

1. По желанию, до удаления приложения: сбрось его разрешения.
   ```bash
   tccutil reset All io.github.amidamaru940.skerry
   ```
2. Закрой Skerry и удали:
   - `/Applications/Skerry.app`
   - `~/Library/Preferences/io.github.amidamaru940.skerry.plist`
   - `~/Library/Application Support/io.github.amidamaru940.skerry`
   - временную папку `Skerry clipboard screenshots` внутри `$TMPDIR` (`open "$TMPDIR"` покажет её)

## Сборка из исходников

Нужен Xcode (Swift 6.1 или новее).

```bash
git clone https://github.com/amidamaru940/skerry.git
cd skerry
open DynamicIsland.xcodeproj   # схема «DynamicIsland», Run
```

По умолчанию приложение подписывается только для твоего Mac. Чтобы подписать его своей (бесплатной) командой Apple ID и разрешения не слетали при пересборке, создай `Config/Local.xcconfig` (git его не видит):

```
DEVELOPMENT_TEAM = ABCDE12345
CODE_SIGN_IDENTITY = Apple Development
```

- **DMG для выпуска:** `scripts/make-release.sh` собирает DMG с ad-hoc подписью только средствами Xcode и macOS.
- **Тесты:** `xcodebuild test -scheme DynamicIsland -destination 'platform=macOS'` и `python3 -m unittest discover tests`. Тесты не ходят в сеть и не трогают настоящие настройки.
