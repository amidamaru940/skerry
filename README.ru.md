## Зачем Skerry

**Скриншоты пачками.** Делай скриншоты как обычно (⇧⌘3, ⇧⌘4, ⇧⌘5). Они складываются в пачку у выреза, и кнопка **«Вставить в Claude · 3»** вставляет всю пачку в приложение, где ты работал. Можно выбрать нужные снимки, перетащить пачку куда угодно, разметить снимок или отправить его по AirDrop. По желанию в пачку попадают и снимки в буфер (⌃⇧⌘3/4). Они хранятся во временной папке и удаляются в течение суток.

**История буфера, которой можно доверять.**
- Всё скопированное — карточками, с поиском (понимает русский), фильтрами и закреплением.
- Пароли не записываются: ни из менеджеров паролей (они помечают копию как секретную), ни из приложений, которые ты исключил.
- История живёт только в памяти, если не включить сохранение на диск.
- Записи удаляются через сутки, одноразовые коды — через 2 минуты.

**Музыка — спокойно.** Обложка, название и ⏮ ⏯ ⏭ видны всегда. Перемешивание, повтор, громкость, вывод звука и тексты появляются, когда курсор над плеером. Рядом **«Далее»** — ближайшие события календаря. Источник **«Авто»** сам выбирает между Spotify, «Музыкой» и браузером. Свайп по свёрнутому вырезу переключает треки.

**Мелочи, сделанные как надо.**
- **«Не засыпать»** с таймером.
- **Полка** для файлов, брошенных на вырез.
- **Пипетка**: копирует цвет и показывает его у выреза, не забирая фокус.
- **Компактный вид**: плеер в одну строку.
- **Горячие клавиши**.
- **Русский и английский**.
- Пока экран показывается или записывается, буфер и скриншоты показывают только заголовки, а вырез молчит.

## Приватность

По умолчанию Skerry **ничего не отправляет в сеть и не слушает портов**.

Каждый сетевой адрес из исходников записан в [`tests/network_allowlist.txt`](tests/network_allowlist.txt) с указанием функции и настройки, которая её включает. Новый адрес без записи ломает тест.

| Функция (включается отдельно) | Что уходит с Mac и куда |
|---|---|
| Погода на экране блокировки | приблизительное место → wttr.in или open-meteo.com |
| Тексты песен | название и исполнитель → lrclib.net, music.163.com (спрашивает перед включением) |
| Значок «explicit», имена исполнителей | название трека → itunes.apple.com, open.spotify.com |
| Анимированные обложки Apple Music | запрос к api.music.apple.com |
| «Лайк» и Canvas в Spotify | вход в Spotify, api.spotify.com |
| Помощник (Screen Assistant) | **скриншоты и текст** → выбранный ИИ-сервис или локальный Ollama |
| Расход ИИ (Claude, Codex, Cursor…) | токены из связки ключей → эти сервисы |
| Сторонние расширения, LocalSend, Quick Share | локальный порт этого Mac / локальная сеть |

Проверка обновлений (Sparkle) выключена. У «зеркала» нет разрешения на камеру.

## Установка

1. Скачай `Skerry-<версия>.dmg` из [Releases](../../releases) и перетащи **Skerry** в «Программы».
2. Skerry бесплатный и не нотаризован: у автора нет платного аккаунта Apple. macOS заблокирует первый запуск. Открой **Системные настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»** рядом со Skerry.
3. Разреши **Универсальный доступ**, когда Skerry попросит. Он нужен, чтобы вставлять в другие приложения одним нажатием.

Каждый выпуск подписан ad-hoc, поэтому macOS считает каждое обновление новым приложением. После обновления выключи и снова включи Универсальный доступ для Skerry. Сборка из исходников со своим Apple ID этого избегает (см. ниже).

Проверить скачанный файл: `shasum -a 256 -c Skerry-<версия>.dmg.sha256`.

## Сборка из исходников

Нужны macOS 15 или новее и свежий Xcode (Swift 6.1 или новее).

```bash
git clone https://github.com/amidamaru940/skerry.git
cd skerry
open DynamicIsland.xcodeproj   # схема «DynamicIsland», Run
```

По умолчанию приложение подписывается только для твоего Mac. Чтобы подписать его своей (бесплатной) командой Apple ID и разрешения не слетали при пересборке, создай `Config/Local.xcconfig` (git его не видит):

```
DEVELOPMENT_TEAM = ABCDE12345
CODE_SIGN_IDENTITY = Apple Development
```

- **DMG для выпуска:** `scripts/make-release.sh` собирает его только средствами Xcode и macOS.
- **Тесты:** `xcodebuild test -scheme DynamicIsland -destination 'platform=macOS'` и `python3 -m unittest discover tests`. Тесты не ходят в сеть и не трогают настоящие настройки.
